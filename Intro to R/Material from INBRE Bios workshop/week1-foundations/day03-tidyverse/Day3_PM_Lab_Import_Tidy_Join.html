2.2 Reading a CSV with Non-Standard Missing Values

Real data files often encode missing values in non-standard ways — "N/A", ".", -99, or a blank cell. Always declare these when reading in:

# tell read_csv() that both "N/A" and blank cells should be treated as NA
students <- read_csv("data/students.csv", na = c("N/A", ""))
students

After reading, clean column names with janitor::clean_names() and fix variable types with mutate() — the same workflow you used on Day 2:

library(janitor)
students <- students |>
  clean_names() |>
  mutate(meal_plan = factor(meal_plan))

2.6 An Anti-Join: Finding Data Quality Problems

# Which tail numbers in flights have no matching record in planes?
flights2 |>
  anti_join(planes, by = "tailnum") |>
  distinct(tailnum) |>
  nrow()
[1] 722

Over 700 flights have tail numbers that don’t appear in planes. These would be silently dropped by an inner_join(). anti_join() makes the problem visible before it causes silent data loss.

4 Quick Reference Card

4.1 Reading Data

Function What it does
read_csv("file.csv") Read CSV; returns a tibble
read_csv("file.csv", na = c("N/A", "")) Declare missing value codes
read_csv("file.csv", skip = n) Skip first n rows
read_excel("file.xlsx", sheet = "name") Read specific Excel sheet
write_csv(df, "output.csv") Write tibble to CSV
clean_names(df) Convert column names to snake_case (janitor)

4.2 Tidy Data

Function What it does
pivot_longer(cols, names_to, values_to) Wide → long
pivot_wider(names_from, values_from) Long → wide
separate(col, into, sep) Split one column into multiple
unite(new_col, col1, col2, sep) Merge multiple columns into one
complete(var1, var2) Make implicit NAs explicit
fill(col) Carry last non-NA value forward
values_drop_na = TRUE Drop NA rows inside pivot_longer()

4.3 Joins

Function Keeps
left_join(x, y, by) All rows of x; NAs where no match in y
inner_join(x, y, by) Only rows with matches in both
full_join(x, y, by) All rows from both; NAs where no match
semi_join(x, y, by) Rows of x that have a match in y
anti_join(x, y, by) Rows of x that have NO match in y

Specifying keys:

# Same name in both tables
left_join(x, y, by = "key")

# Different names in each table
left_join(x, y, by = c("x_col" = "y_col"))

# Compound key (multiple columns)
left_join(x, y, by = c("col1", "col2"))

4.4 Useful Reminders

  • Numeric column names need backticks: `1999`, `2000`
  • Check for join problems with anti_join() before your main join
  • na.rm = TRUE is needed in mean(), sd(), sum() etc. whenever NAs are present
  • After pivot_longer(), always check the result with str() and head()
